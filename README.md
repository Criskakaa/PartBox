# 零件簿｜PartsBook
> 个人DIY、机械爱好者使用的紧固件零件库存管理APP。
> 仅手动录入数据，**无图像识别**，用于管理螺丝、螺母、垫片等标准件，支持分类筛选、库存记录、存放位置备注、CSV备份。

## ✨功能特性
- 零件信息录入：类别、头型、螺纹规格(M2/M3/M4/M5…)、长度、库存数量、存放位置、备注、可选关联照片
- 多条件组合筛选：按零件大类、头部类型、螺纹规格、长度快速过滤零件
- 全文搜索：直接输入`M3 杯头`快速检索零件
- 本地SQLite数据库，所有数据保存在手机本地，不上传云端
- CSV导出 / 导入备份，防止数据丢失
- 编译产物为标准Android APK，鸿蒙系统可直接兼容运行

## 🚀构建方式
本项目使用 GitHub Actions 在线编译，无需本地安装 Flutter、Android Studio。
1. Fork 本仓库
2. 进入 `Actions` → 选择 `Build Android APK`
3. 点击 `Run workflow` 触发构建
4. 构建完成后在 Artifacts 下载编译好的 `app‑release.apk`
5. 将APK安装到安卓/鸿蒙手机，开启允许安装未知来源应用权限

## 📝使用说明
1. 打开APP，点击新增零件，手动填写零件全部参数并保存
2. 在列表页使用筛选器或者搜索框查找零件
3. 可编辑、修改库存数量、删除条目
4. 定期导出CSV文件做好数据备份

## ⚠️注意事项
- 无AI拍照识别功能，全部信息需要手动录入
- 编译输出为未签名APK，适合个人自用，不用于应用商店上架
- 鸿蒙系统安装需要手动开启「允许安装未知应用」权限
